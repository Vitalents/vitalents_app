## Neutral summary (written by the library agent from this source; not a quotation; needs review)

The paper describes how the Cognition battery was built for repeated use with astronauts. It has several unique versions of each test so that repeated sessions do not simply repeat the same items, and the authors report that practice effects differ between tests. They present normative data from a high-performing sample for comparison with spaceflight and analog data.
