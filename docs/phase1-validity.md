# Phase-one implementation evidence and limits

14 November 2026. This records the scope of the fixes, not a clinical endorsement or an official submission receipt.

- **Engine:** app behavior follows the D-10 demonstration contract and shared vectors. The independent Python research estimator has a different scope. Simulation outcomes and software consistency checks do not establish clinical validity.
- **Follow-ups:** marking a step done without a suitable later reading keeps it awaiting review. A suitable later observation must match subject, time window, indicator and quality requirements. Reviewing it is explicit; closure remains a separate owner action with a reason. No observed change is attributed to the step.
- **Scientific sources:** the automated audit retrieved 34 source URLs and matched 97 display excerpts and 168 corpus fragments. Nine confirmed page locators were corrected and an ambiguous executive-summary locator resolved. `ai/source_verification.json` retains snapshot hashes, counts and limits. Printed PDF pages and physical PDF indices are different; Markdown notes have no original-source page number. The Food and Nutrition PDF has a Rev E cover and quoted pages carrying Rev D; that conflict is preserved.
- **Source approval and rights:** every source remains draft. Text matching is not human approval, clinical review or legal clearance. NTRS public-use determinations are recorded where verified; other source-specific and third-party rights remain uncertain.
- **Recorded answers:** `ai/recordings/2026-11-14-gptoss20b.raw.json` preserves the exact original five-entry cache from commit `49f04fa`. `ai/cache_review.json` binds publication decisions to entry hashes. Sleep and pulse explanations are withheld because of overstatement/source-support gaps. The retained light explanation is unchanged, with citation metadata corrected separately. No scientific rewrite is represented as model output. New or changed entries default to withheld pending review.
- **Live AI:** guardrails check selected patterns, citation membership, sentence markers and unsupported numbers. They do not determine semantic entailment. The stored model evaluation reports 9/10 expected source-title matches and 5/5 expected abstentions, not scientific accuracy. It predates corrected source metadata. No new live-model or clinical evaluation was performed for these fixes.
- **Operating scope:** simulated histories and synthetic research examples; live Decode is separately labelled. Local role views are not user authentication. Delayed sharing is simulated. Initial loading and uncached assets need network access; the assistant is optional. Cloudflare builds force the reviewed cached assistant; live backend updates and semantic review remain separate.

Source/cache regressions run with `python3 -m pytest ai/tests -q`; follow-up regressions run with `cd app && npx vitest run src/features/followups`. Repository integration, built-artifact and deployed-URL checks must be assessed separately. Final video/deck, exact challenge resource eligibility, event registration and current official submission requirements remain in `submission/checklist.md`.
