# Research and operational boundaries

The original Task 2 open-decision list predates the frozen application contract. IDs, nulls, timestamps, schemas, event conventions, scenario numbering and feedback format are defined in [the current contract](../../docs/CONTRACT_P0.md). These are the remaining evidence boundaries, not unassigned build tasks:

- **Temperature:** export-specific temperature units and signed-field meanings need verification before physiological interpretation. Skin temperature is not core body temperature.
- **Personal reference:** minimum counts, lookback windows and comparison bands are demonstration policies. Clinical interpretation requires independent validation.
- **Real-data research:** LifeSnaps is an attributed Earth-based dataset, not astronaut data. The project contract records CC BY 4.0 for v4; attribution and privacy constraints still apply. No participant-level files are distributed here and no measured LifeSnaps result is claimed for the app.
- **Measurement:** software scoring tests do not validate the custom Decode task as a clinical instrument. Target-device timing and independent measurement studies remain separate evidence requirements.
- **Operations:** browser role views and delayed sharing demonstrate workflow, not authenticated clinical accounts or real mission communication.
- **Challenge eligibility:** scientific source citations do not establish an exact qualifying match to the official challenge resource list or prove official submission.

See [validation](../../docs/validation.md) and [data sources](../../docs/science/data-sources.md) for scope and provenance.
